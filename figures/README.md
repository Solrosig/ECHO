# Report figures: one script per figure

Every figure in the project report is generated by one Python script in this folder, with matplotlib 3.10.9. Each script writes the file named beside it; the report embeds that file at its full width, so one point in the figure is one point on the page. Results figures are built at the text-column width of 6.10 in and design figures at 6.30 in, all at 300 dpi, in Liberation Serif, monochrome. `make_all_figures.py` rebuilds the whole set in report order; any single figure can be rebuilt with its own script.

## How to rebuild

Run from this folder with Python 3.11 or later and the packages in `requirements-figures.txt`:

    python make_all_figures.py

The results scripts read the frozen tables in `../research/` through `echo_figdata.py` (in the report's evidence bundle the same module finds them in `04 Data - acoustic` and `05 Data - listener and instruments`); it also joins the acoustic separation table to the scorecard for Figures 5.3, 5.4 and 5.10. Figure 5.9 needs statsmodels for its mixed model; Figure 5.10 uses SciPy for the Spearman p-value when it is installed and an equivalent built-in routine otherwise. The shared style lives in `echo_figstyle.py`, the drawing helpers for the design figures in `echo_diagram.py`.

## Provenance

The results scripts are the per-figure split of the combined scripts that produced the earlier figure files (`make_figures.py`, `make_figures_abc.py`, `make_figure_d.py`), and their output is pixel-identical to the figures embedded in the report. The nine design figures had no source before the final figure review of 27 September 2026; they were redrawn from the originals in the same style with `echo_diagram.py`, and the report now embeds the scripted versions. Changes made by that review: Figure 5.4 gained the second naturalness anchor (natural emotional speech, 3.353); Figures 5.7 and 5.8 state the direction of the reduction as the captions define it; Figure 5.9 uses the report's terms for its axes; Figure 5.11 heads its boxed column "Configuration mean"; Figure 5.6 lost a blank band; the note under Figure 4.7 was re-set clear of the connector; the footnote of Figure 4.4 states what the bold connectors show; Figure E.1 was redrawn in the house style with items numbered 1.1 to 7.4.
