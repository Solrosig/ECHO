# Listening notes

Diagnostic clips kept as **evidence for decisions taken by ear**, with the description that
produced them and the listener's verdict recorded alongside.

They exist because the project's objective instruments cannot settle these questions. The
dimensional recogniser reads valence at chance (M1, 2026-08-31), and UTMOS would score a
calm, clear, *wrong* clip highly. When a design choice turns on whether something **sounds**
right, the only instrument is a person — so the judgement is written down at the time, with
the stimulus, rather than reconstructed later.

**Convention.** Every clip is timestamped and never overwritten. Each batch carries a CSV
recording, per clip: the exact description or instruction sent to the engine, the listener's
verdict in their own words, duration, peak, RMS, seed, and date. Acoustics are included
because they are what a naive reading would use — and on 2026-08-31 they were misleading:
a clip 32 % faster and 26 % louder was read as "angry" from the numbers and heard as
"rushed and flat" by the listener.
